## 🔧 What I'm working on now

**[CertiHarvest](https://certiharvest.com) · CTO**

A first-mile transparency platform for the seafood industry. Harvest data gets verified where it's caught and carried intact through the supply chain. I built the V1 platform from scratch in 2026, including:
- A full-stack web app: TypeScript, Next.js, Node.js, PostgreSQL, Docker, and Kubernetes on DigitalOcean
- Native iOS and Android apps in React Native with offline queuing, so data captured without a connection syncs automatically once the device is back online
- A lineage data model that tracks product through splits, aggregations, and transformations, with FDA FSMA 204 Traceability Lot Codes generated at exactly the points the rule requires
- A seafood compliance scorecard that answers the question buyers and sellers actually ask: "Can I sell into this market today?" It scores a company's data against four regulation profiles (FDA FSMA 204, NOAA's Seafood Import Monitoring Program (SIMP), EU catch certification, and EU Article 58), covering 92 requirements and a 71-element data catalog. Regulations are stored as data, not code, so adding a new one, or a large buyer's private sourcing standard, means adding a data file, not starting a new project. Compile-time checks and golden test cases make sure a bug can't silently inflate a score.
- BLE/NFC IoT device workflows for capturing harvest events on the vessel and monitoring temperature, with GPS privacy masking built in
- Production monitoring and alerting with Sentry and Better Stack
